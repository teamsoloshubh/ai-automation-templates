# AI Automation Templates

Reusable templates and demos for selling AI automations to experts — doctors, e-commerce, real estate, hotels.

WhatsApp automation, voice agents, lead follow-up. Sales-ready artifacts.

## Template Structure

Each template includes:
- Working n8n workflow (JSON)
- Setup guide (non-coder friendly)
- Demo video script
- Pricing proposal template
- Client onboarding checklist

## How to Use

1. Pick a template matching your client industry
2. Clone the template
3. Replace placeholder data with client details
4. Set up WhatsApp gateway + LLM + database
5. Demo to client using the demo script
6. Close the deal
